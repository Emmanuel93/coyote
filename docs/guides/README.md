# Guías

Cada guía resuelve una tarea concreta. Si es tu primera vez, empieza por el [tutorial](../tutorial/primeros-15-minutos.md). Para el detalle de cada formato o comando están las [especificaciones](../specs/) y la [referencia de comandos](../reference/cli.md).

| Guía | Para qué |
| --- | --- |
| [El gate en tu IDE](gate-en-tu-ide.md) | Instalar el gate en Claude Code, Cursor, Codex, Gemini CLI, Copilot o Windsurf, medir su nivel y aprobar lo que piden los agentes |
| [PRD: del problema al plan](prd.md) | Escribir el PRD del producto y el de cada feature, y partir de él en el plan |
| [Contexto para agentes](contexto.md) | Notas, paquetes de contexto, preguntas y cómo medir con un golden si el contexto sirve |
| [Workstreams](workstreams.md) | Un plan de varios pasos de agentes, con topes, puntos de revisión y su costo real |
| [El pipeline de PRs](pipeline-de-prs.md) | El impacto y el riesgo de cada PR, quién tiene que aprobar y gitleaks |
| [El hub de la organización](hub.md) | Un estándar, admins y presupuesto para todos los proyectos |
| [SLOs y alertas](slos.md) | Alertas de Prometheus generadas desde un archivo y revisadas en cada PR |
| [Secretos e infraestructura](secretos-e-infra.md) | Qué no puede leer un agente y qué no puede aplicar nunca |
| [Auditoría](auditoria.md) | El reporte del mes y qué hacer con sus avisos |
